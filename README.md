## :open_file_folder: Repository organisation

The solution of the problems can be found in the **problems.ipynb** within this repository. The notebook is organised so each problem has its own section. Within each section problem, I have stated in my own words the main learning objectives of each problem, and then, each problem contains an **Interpretation and Conclusions** subsection, where I explain the results obtained.

## :construction_worker: Installation

Simply clone this repository by running terminal in your desired local folder and writting:

```
git clone "https://github.com/gfmg/as_project.git"
```

This will automatically download all the repo folders and files into your local folder. You need to have installed `VS Code` (or any other text editor) and `Python` to run the **problems.ipynb** Jupyter notebook. 

If you do not have Git, VScode or Python installed here are some useful links:

- Git: https://git-scm.com/downloads
- VS Code: https://code.visualstudio.com/
- Python: https://www.python.org/; https://realpython.com/installing-python/
